# نقشه راه توسعه Cloud Financial X

این سند شامل فازهای توسعه‌ای پیشنهادی برای پیشرفت پروژه به سمت یک سیستم مالی ابری مدرن و کامل است.

## فاز 1: تثبیت هسته محلی و ساختار داده

هدف: اطمینان از ثبات مدل‌های محلی و همگرایی تغییرات.

- تکمیل و بازبینی جداول Drift موجود
- اطمینان از صحت روابط Journal و JournalRow
- افزودن پشتیبانی از currencyCode و مبنای مالی در مدل‌های حسابداری
- بازبینی و تقویت Repositoryها برای تراکنش‌های اتمیک
- افزودن تست‌های واحد پایه برای Repositoryها و Mapperها

## فاز 2: پیاده‌سازی Sync Queue و زیرساخت همگام‌سازی

هدف: آماده‌سازی ساختار Outbox برای همگام‌سازی پایدار.

- تایید ساختار SyncQueue در Drift
- گسترش SyncQueueRepository برای مدیریت وضعیت‌ها و خطاها
- پیاده‌سازی مکانیسم batch برای ارسال رکوردهای در انتظار
- افزودن متریک و log برای عملیات sync
- طراحی مدل API سرور برای دریافت رکوردهای همگام‌سازی

## فاز 3: توسعه لایه ورود هوشمند اطلاعات

هدف: ساخت یک مسیر ورودی جدید برای تصاویر، صدا و متن.

- تعریف مدل Draft/Event برای داده‌های استخراج‌شده
- پیاده‌سازی صفحات UI برای بارگذاری تصویر و صوت
- افزودن سرویس OCR محلی یا ابری در backend
- افزودن سرویس Speech-to-Text برای فایل‌های صوتی
- پیاده‌سازی موتور استخراج موجودیت (NLP/NER)
- ساخت Draft Event Builder و local draft storage
- اضافه کردن صفحه تایید/اصلاح کاربر قبل از ثبت نهایی

## فاز 4: پیوند Smart Intake با جریان اصلی حسابداری

هدف: انتقال Draftهای تاییدشده به تراکنش‌های حسابداری واقعی.

- تبدیل Draft به Journal/JournalRow یا Invoice
- ثبت همزمان داده و enqueue در SyncQueue
- افزودن بررسی تطبیق ارز/مبنای مالی
- پیاده‌سازی قوانین تعادل‌سازی دوطرفه
- تست گردش کامل ثبت و ویرایش

## فاز 5: پیاده‌سازی Backend Java/Spring Boot

هدف: ایجاد سرویس پردازش و API قابل اعتماد.

- راه‌اندازی Spring Boot project با ماژول‌های زیر:
  - Auth
  - Draft Intake
  - Processing
  - Sync
- تعریف REST API برای دریافت draft، ثبت داده و مشاهده وضعیت sync
- افزودن Spring Security + JWT
- پیاده‌سازی persistence در PostgreSQL/MySQL
- طراحی و پیاده‌سازی صف پیام (RabbitMQ یا Kafka)

## فاز 6: پشتیبانی پیشرفته از چند ارز و مبنا

هدف: تکمیل حسابداری چندارز و تبدیل نرخ.

- تعریف دقیق فیلدهای ارز در Journal و JournalRow
- افزودن موجودیت‌های نرخ تبدیل و تاریخ اثر
- پیاده‌سازی محاسبه خودکار تبدیل ارز برای گزارش‌ها
- ایجاد گزارش‌های چندارزی و تفکیک بر اساس مبنا
- افزودن گزینه‌های تنظیمات ارز و مبنای مالی در UI

## فاز 7: گزارش‌دهی و ماژول‌های تجاری

هدف: تکمیل تجربه مالی و گزارش‌گیری.

- ساخت داشبورد مالی و وضعیت نقدینگی
- افزودن گزارش اسناد حسابداری
- افزودن گزارش هزینه و مرکز هزینه
- تکمیل ماژول فاکتور فروش
- آماده‌سازی پایه برای انبار و حقوق و دستمزد

## فاز 8: پایانی و آماده‌سازی تولید

هدف: آماده‌سازی برای انتشار و نگه‌داری.

- رفع باگ‌ها و بهبود پایداری
- نوشتن تست‌های واحد و integration
- مستندسازی API و معماری
- آماده‌سازی نسخه‌ی اولیه تولیدی
- بررسی مسائل امنیتی و سرعت عملکرد
